Viralo Growth Mechanics SDK — React Components

InviteGate

Gate premium content behind a configurable number of invites with a visual progress indicator. Use requiredInvites and currentInvites props.

import { InviteGate } from '@viralo/react';

<InviteGate
  requiredInvites={3}
  currentInvites={0}
  primaryColor="#EF4444"
>
  <div>Protected content</div>
</InviteGate>

PoweredByBadge

Configurable attribution watermark with custom branding and styling. Supports compact mode and custom brand URL.

import { PoweredByBadge } from '@viralo/react';

<PoweredByBadge
  brandName="Viralo"
  brandUrl="https://viralo.dev"
  primaryColor="#EF4444"
  compact={false}
/>
